## ตอนที่ 4 — สำรวจข้อมูลขั้นที่ 3: ค่าไหนสุดโต่ง และเป็นของจริงหรือข้อมูลผิด (30 นาที)

ทำบนแท็บ `สำรวจข้อมูล flights`

### 4.1 Box Plot และนิยามของ "outlier" (18 นาที)

**ถามด้วย SQL ก่อน (6 นาที)** — SQL Lab · Database `examples` · บันทึกชื่อ `eda7_outlier_<รหัสนักศึกษา>`

```sql
-- ควอร์ไทล์ของ delay ขาออก แยกรายสายการบิน (NTILE(4) แบ่งแต่ละสายเป็น 4 ส่วนเท่า ๆ กัน)
SELECT AIRLINE, COUNT(*) AS flights,
       MAX(CASE WHEN q = 1 THEN DEPARTURE_DELAY END) AS q1,
       MAX(CASE WHEN q = 2 THEN DEPARTURE_DELAY END) AS median,
       MAX(CASE WHEN q = 3 THEN DEPARTURE_DELAY END) AS q3
FROM (SELECT AIRLINE, DEPARTURE_DELAY,
             NTILE(4) OVER (PARTITION BY AIRLINE ORDER BY DEPARTURE_DELAY) AS q
      FROM flights WHERE DEPARTURE_DELAY IS NOT NULL)
GROUP BY AIRLINE
ORDER BY median
```

ลอกค่าของ AA กับ VX ลงตาราง แล้ว **คำนวณขอบบนเอง**: ขอบบน = Q3 + 1.5 × (Q3 − Q1)

| สายการบิน | Q1 | median | Q3 | ขอบบน 1.5×IQR | ช้าเกินขอบกี่เที่ยว (ข้อ 4) |
|---|---|---|---|---|---|
| AA | | | | (ควรได้ 79.5) | |
| VX | | | | (ควรได้ 18.5) | |

ย้อนดูใบงานสัปดาห์ 6: ค่ากลางของ AS กับ MQ ที่คุณ **ประมาณด้วยตา** จาก histogram ตรงกับ `median` ที่ SQL ให้วันนี้ไหม (AS = −2, MQ = 9)

**ดูด้วยกราฟ (12 นาที)**

1. สร้างกราฟชนิด **Box Plot** metric `DEPARTURE_DELAY` · Distribute across = `AIRLINE` · Time Range `No filter` · **Whisker type = Tukey** ตั้งชื่อ `outlier ตามสายการบิน <รหัส>`
2. ชี้เมาส์ที่กล่อง **AA** อ่าน Q1, median, Q3 เทียบกับที่ได้จาก SQL — ควรตรงกันหรือต่างไม่เกิน 1 นาที (วิธีแบ่งควอร์ไทล์ของสองเครื่องมือต่างกันเล็กน้อย)
   **สิ่งที่กราฟให้แต่ SQL ไม่ให้:** เห็น 14 สายพร้อมกันว่ากล่องไหนสูง กล่องไหนแคบ และจุดนอกขอบลากไปไกลแค่ไหน
3. สลับ Whisker type เป็น **Min/max** แล้ว **Percentile 2/98** ดูว่าจุด "outlier" หายไปหรือเพิ่มขึ้น
4. กลับไป SQL Lab นับว่าตามนิยาม Tukey มี outlier กี่เที่ยว (แก้ชื่อสายและตัวเลขขอบตามตารางข้างบน)

```sql
SELECT AIRLINE, COUNT(*) AS flights, SUM(DEPARTURE_DELAY > 79.5) AS beyond_fence
FROM flights WHERE AIRLINE = 'AA' AND DEPARTURE_DELAY IS NOT NULL
GROUP BY AIRLINE
```

AA ควรได้ 423 จาก 5,158 เที่ยว (8.2%) · VX ควรได้ 60 จาก 573 เที่ยว (10.5%) — VX ตรงเวลากว่าแต่มี outlier สัดส่วนมากกว่า เพราะขอบของ VX แคบกว่ามาก

> **outlier ไม่ใช่คุณสมบัติของข้อมูล มันคือคุณสมบัติของนิยามที่คุณเลือก**
> เที่ยวบินช้า 60 นาทีเป็น outlier ของ VX (ขอบ 18.5) แต่เป็นเรื่องปกติของ AA (ขอบ 79.5)

### 4.2 ของจริง หรือข้อมูลผิด (12 นาที)

1. สร้าง **Table** คอลัมน์ `AIRLINE` `ORIGIN_AIRPORT` `DESTINATION_AIRPORT` `ds` `DEPARTURE_DELAY` `ARRIVAL_DELAY` · เรียง `DEPARTURE_DELAY` มาก→น้อย · Row limit 20 ตั้งชื่อ `20 เที่ยวที่ช้าที่สุด <รหัส>`
2. ดูแถวบนสุด: ช้า **1,380 นาที** (23 ชั่วโมง) แล้วดูคอลัมน์ข้าง ๆ

| ตรวจอะไร | ผลที่เห็น | สรุปว่าจริงหรือผิด |
|---|---|---|
| `ARRIVAL_DELAY` ของแถวเดียวกันใกล้เคียง `DEPARTURE_DELAY` ไหม | | |
| ค่าที่ช้าที่สุด 5 อันดับเป็นสายเดียวกัน วันเดียวกันไหม | | |
| มีค่าลบผิดปกติไหม (ต่ำสุด −39 = ออกก่อนเวลา 39 นาที) | | |

> วิธีแยก "ของจริง" จาก "ข้อมูลผิด" คือ **ดูคอลัมน์ข้างเคียงว่าสอดคล้องกันไหม** ถ้าออกช้า 1,380 แล้วถึงช้า 1,384 ตัวเลขสองตัวที่บันทึกแยกกันตรงกัน — นั่นคือเที่ยวบินที่ค้างข้ามคืนจริง ไม่ใช่มีคนพิมพ์เลขเกิน
