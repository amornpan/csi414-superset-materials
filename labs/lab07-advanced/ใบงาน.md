## วัตถุประสงค์

1. ใช้ **Rolling Window** ทำค่าเฉลี่ยเคลื่อนที่ และรู้ว่ามันกลบอะไรไป
2. ตั้ง **Min Periods** ให้ถูก เพื่อไม่ให้ช่วงต้นกราฟหลอกตา
3. ใช้ **Time Comparison** เทียบกับช่วงก่อนหน้า
4. ใส่ **Annotation Layer** เพื่อบอกว่าเส้นอ้างอิงคืออะไร

## ตอนที่ 1 — ค่าเฉลี่ยเคลื่อนที่ 7 วัน (35 นาที)

1. สร้างกราฟ **Line Chart** ใหม่จาก `tutorial_flights`

| ช่อง | ค่าที่ตั้ง |
|---|---|
| X-axis | `Travel Date` |
| Time Grain | **Day** |
| Metrics | `AVG(Cost)` |
| Time Range | `No filter` |

2. กด Create chart แล้ว **จดไว้ก่อนว่าเส้นดิบหน้าตาเป็นอย่างไร**
3. เปิดแท็บ **Advanced Analytics** แล้วตั้งค่าในกล่อง **Rolling Window**

| ช่อง | ค่าที่ตั้ง |
|---|---|
| Rolling Function | **mean** |
| Periods | **7** |
| Min Periods | **7** |

**เทียบก่อนกับหลัง**

| | เส้นดิบ (ไม่ตั้ง rolling) | เส้นเฉลี่ยเคลื่อนที่ 7 วัน |
|---|---|---|
| ความขรุขระ | | |
| จุดสูงสุดอยู่ตรงไหน | | |
| ตอบคำถามอะไรได้ดีกว่า | | |

> ### Min Periods คือช่องที่คนข้ามบ่อยที่สุด และเป็นช่องที่หลอกตาที่สุด
>
> ถ้าไม่ตั้ง Min Periods วันแรกของข้อมูลจะถูกคำนวณจากข้อมูลวันเดียว
> วันที่สองจากสองวัน ไล่ไปเรื่อย ๆ **เส้นช่วงต้นจึงเป็นค่าเฉลี่ยของข้อมูลไม่ครบ**
> แต่มันถูกวาดด้วยเส้นแบบเดียวกันเป๊ะกับส่วนที่ครบ คนอ่านจึงแยกไม่ออก
>
> ตั้ง Min Periods เท่ากับ Periods แล้วช่วงที่ข้อมูลไม่ครบจะหายไปจากกราฟ ซึ่งเป็นสิ่งที่ถูก

4. ตั้งชื่อ `ค่าตั๋วเฉลี่ยแบบเฉลี่ยเคลื่อนที่ 7 วัน <รหัสนักศึกษา>` แล้วบันทึกลงแดชบอร์ด **แท็บเจาะลึก**


## ตอนที่ 2 — Annotation ที่บอกว่าเส้นนี้คืออะไร (20 นาที)

ที่กราฟเดิม เปิดแท็บ **Annotations and Layers** แล้วกด **Add annotation layer**

| ช่อง | ค่าที่ตั้ง |
|---|---|
| Name | `เส้นเป้าหมายค่าตั๋วเฉลี่ย 1,500 ปอนด์` |
| Annotation Layer Type | **Formula** |
| Value | `y=1500` |
| Style | Dashed |

> **เส้นประที่ไม่มีชื่อ คือเส้นที่คนอ่านต้องเดาว่ามันคืออะไร**
> ช่อง Name ไม่ใช่ของประดับ มันคือคำอธิบายที่จะไปโผล่ในคำบรรยายของกราฟ
> ระบบตรวจของแล็บนี้เช็กว่าคุณตั้งชื่อ layer หรือยัง

## บันทึกสัปดาห์นี้ (ต้องเขียน)

เปิดกล่อง Markdown บนแดชบอร์ดของคุณ แล้วเขียนต่อท้ายของเดิม

```markdown
## บันทึกสัปดาห์ที่ 7

(เขียนที่นี่ อย่างน้อย 60 ตัวอักษร)
```

**ห้ามลบบันทึกของสัปดาห์ก่อน** ตัวตรวจตรวจสะสม ลบแล้วตกย้อนหลัง
เหมือนลบกราฟเก่าทิ้ง

สิ่งที่ควรเขียนถึง

- ค่าเฉลี่ยเคลื่อนที่ 7 วันทำให้เห็นอะไรชัดขึ้น และกลบอะไรหายไป
- การเทียบกับช่วงก่อนหน้าตอบคำถามอะไรที่ตัวเลขดิบตอบไม่ได้
- การเลือกช่วงเฉลี่ยเคลื่อนที่ให้ยาวขึ้น ได้อะไรและเสียอะไร และคุณจะเลือกอย่างไรถ้าต้องเลือกจริง

> เขียนสิ่งที่ **เห็น** ไม่ใช่สิ่งที่ **ทำ**
> "ทำกราฟเส้นเสร็จแล้ว" ไม่ได้บอกอะไรกับคนอ่าน
> "เปลี่ยนจาก SUM เป็น AVG แล้วรูปเปลี่ยนไปคนละเรื่อง" บอก
