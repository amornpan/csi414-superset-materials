## ตอนที่ 1 — คดีที่ 1 วงกลม 66 ชิ้น (30 นาที)

เปิดกราฟ `สัดส่วนค่าตั๋วรายสายการบิน <รหัส>` ที่คุณทำไว้สัปดาห์ที่แล้ว

**บันทึกคำพิพากษา**

| คำถาม | คำตอบของคุณ |
|---|---|
| กราฟนี้ตั้งใจตอบคำถามอะไร | |
| ชิ้นที่ใหญ่ที่สุดคือสายการบินอะไร ดูออกไหม | |
| อันดับ 2 กับอันดับ 3 ต่างกันเท่าไร ดูออกไหม | |

**วิธีแก้** สร้างกราฟใหม่ชนิด **Bar Chart** ที่ตอบคำถามเดิม

| ช่อง | ค่าที่ตั้ง |
|---|---|
| X-axis | `Airline` |
| Metrics | `AVG(Cost)` |
| Row limit | **10** |
| Sort Descending | เปิด |
| X Axis Title / Y Axis Title | `สายการบิน` / `ค่าตั๋วเฉลี่ย (ปอนด์)` |

ตั้งชื่อ `ค่าตั๋วเฉลี่ยรายสายการบิน 10 อันดับ <รหัสนักศึกษา>` บันทึกลงแดชบอร์ดเดิม

**แล้วลบกราฟวงกลมทิ้ง** ทั้งจากแดชบอร์ดและจากหน้า Charts

> **ระบบตรวจของสัปดาห์นี้จะตกทันทีถ้ายังเจอกราฟวงกลมอยู่ในไฟล์**
> ไม่ใช่เพราะกราฟวงกลมผิดเสมอ แต่เพราะกรณีนี้มันตอบคำถามที่คุณตั้งไว้ไม่ได้


## ตอนที่ 2 — คดีที่ 2 แกนที่ไม่เริ่มที่ศูนย์ (35 นาที)

สร้างกราฟแท่งเทียบ **ค่าตั๋วเฉลี่ยของ Business กับ Premium Economy** โดย

1. ทำครั้งแรกโดย **ไม่ตั้ง** Y Axis Bounds แล้วบันทึกภาพหน้าจอไว้ดู
2. ทำครั้งที่สองโดยตั้ง **Y Axis Bounds** เป็น `0` ถึงเว้นว่าง

**ตัวเลขจริงจากข้อมูลชุดนี้**

| ชั้นโดยสาร | ค่าตั๋วเฉลี่ย (ปอนด์) |
|---|---:|
| Business | 1,657.6 |
| Premium Economy | 1,636.1 |

สองค่านี้ต่างกัน **1.3 เปอร์เซ็นต์**

| แบบ | แท่งสองแท่งดูต่างกันแค่ไหน | คนอ่านจะสรุปว่าอย่างไร |
|---|---|---|
| แกนไม่เริ่มที่ศูนย์ | | |
| แกนเริ่มที่ศูนย์ | | |

**ให้เก็บแบบที่แกนเริ่มที่ศูนย์ไว้บนแดชบอร์ด** และตั้งชื่อให้ชัด

> **แกนที่ตัดฐานไม่ได้ผิดกฎหมาย** สื่อและรายงานผลประกอบการใช้กันทุกวัน
> สิ่งที่ผิดคือใช้มันแล้วไม่บอกคนอ่านว่าใช้อยู่

## บันทึกสัปดาห์นี้ (ต้องเขียน)

เปิดกล่อง Markdown บนแดชบอร์ดของคุณ แล้วเขียนต่อท้ายของเดิม

```markdown
## บันทึกสัปดาห์ที่ 4

(เขียนที่นี่ อย่างน้อย 60 ตัวอักษร)
```

**ห้ามลบบันทึกของสัปดาห์ก่อน** ตัวตรวจตรวจสะสม ลบแล้วตกย้อนหลัง
เหมือนลบกราฟเก่าทิ้ง

สิ่งที่ควรเขียนถึง

- กราฟวงกลมของคุณอ่านไม่ออกตรงไหน และกราฟแท่งที่ทำแทน แก้ปัญหานั้นได้อย่างไร
- ความต่าง 1.3 เปอร์เซ็นต์ ดูเหมือนต่างกันเท่าไรเมื่อแกนไม่เริ่มที่ศูนย์ และเรื่องนี้สำคัญกับการตัดสินใจอย่างไร
- คุณเจอปัญหาอะไรเพิ่มในงานของตัวเอง และทำไมตอนสร้างครั้งแรกคุณถึงไม่เห็นมัน

> เขียนสิ่งที่ **เห็น** ไม่ใช่สิ่งที่ **ทำ**
> "ทำกราฟเส้นเสร็จแล้ว" ไม่ได้บอกอะไรกับคนอ่าน
> "เปลี่ยนจาก SUM เป็น AVG แล้วรูปเปลี่ยนไปคนละเรื่อง" บอก
