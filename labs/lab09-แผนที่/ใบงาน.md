## วัตถุประสงค์

1. วาดจุดพิกัดบนแผนที่ด้วย **deck.gl layer** ใน Superset
2. เจอปัญหา **จุดทับกัน** ด้วยตาตัวเอง แล้วแก้ด้วยการ **รวมจุดเป็นช่อง**
3. อธิบายได้ว่าจุดทับกันจนดำทั้งแผนที่ ไม่ใช่ปัญหาเรื่องสี แต่เป็นปัญหาเรื่องการรวมข้อมูล
4. ตั้งคำถามได้ว่า **ความหนาแน่นของจุดบนแผนที่ แทนอะไรกันแน่**

## ข้อมูลที่ใช้

**Dataset `san_francisco`** — ที่อยู่ในเมืองซานฟรานซิสโก **261,552 แถว**
เป็นชุดข้อมูลตัวอย่างทางการของ Apache Superset ชุดเดียวกับที่เอกสารทางการใช้เดโม deck.gl

| คอลัมน์ | ความหมาย |
|---|---|
| `LAT` / `LON` | พิกัดของที่อยู่ |
| `STREET` · `NUMBER` | ชื่อถนนและเลขที่ |
| `DISTRICT` · `POSTCODE` | เขตและรหัสไปรษณีย์ ใช้ทำตัวกรอง |

> **ทำไมแล็บนี้ถึงเปลี่ยนไปใช้ข้อมูลคนละชุด**
> `tutorial_flights` ที่ใช้มาแปดสัปดาห์ มีพิกัดสนามบินแค่ **113 จุดที่ไม่ซ้ำกัน**
> จุดทับกันของมันคือจุดเดียวกันเป๊ะซ้อนกันหลายร้อยครั้ง ซึ่งเป็นคนละเรื่องกับปัญหาจริง
> ที่เกิดจากจุดพิกัดต่างกันเล็กน้อยแล้วเบียดกันจนอ่านไม่ออก

> **จุดที่คนพลาดบ่อยที่สุดในแล็บนี้** ใส่ละติจูดกับลองจิจูดสลับกัน
> แล้วจุดทั้งหมดจะไปโผล่กลางมหาสมุทรอินเดีย ถ้าเจออาการนี้ อย่าเพิ่งโทษข้อมูล
> ให้กลับไปดูช่อง Latitude กับ Longitude ก่อนเสมอ **ระบบตรวจจับความผิดพลาดนี้ด้วย**

## ตอนที่ 1 — จุดดิบบนแผนที่ (30 นาที)

1. สร้างกราฟใหม่จาก `san_francisco` ชนิด **deck.gl Scatterplot**
2. ที่ช่อง **Longitude & Latitude** เลือกแบบ `latitude/longitude columns`
   แล้วใส่ `LAT` กับ `LON` **ให้ถูกช่อง**
3. **Time Range** = `No filter` · **Row limit** ลองตั้งที่ `10000` ก่อน
4. กด Run ดูผล แล้วค่อยเพิ่มเป็น `100000`
5. ตั้งชื่อ `ที่อยู่แต่ละจุดในซานฟรานซิสโก <รหัสนักศึกษา>` บันทึกลงแดชบอร์ด `csi414_<รหัส>`

**บันทึกสิ่งที่เห็น**

| Row limit | ใช้เวลาโหลดกี่วินาที | ตรงกลางเมืองยังนับจุดได้ไหม |
|---:|---:|---|
| 10,000 | | |
| 100,000 | | |

> **ทำไมต้องเริ่มที่หนึ่งหมื่นจุดก่อน**
> การวาดแสนจุดใช้เวลาและแรงเครื่องมาก ถ้าตั้งค่าผิดแล้วต้องแก้ คุณจะเสียเวลารอทุกครั้งที่กด Run
> ให้ตั้งค่าจนถูกก่อนด้วยข้อมูลน้อย ๆ แล้วค่อยเพิ่ม


## ตอนที่ 2 — รวมจุดให้อ่านออก (35 นาที)

สิ่งที่คนมักลองก่อนแล้วไม่ได้ผล

| วิธีที่มักลอง | ทำไมไม่ได้ผล |
|---|---|
| ลดความทึบของจุด | ช่วยได้นิดเดียว พอจุดทับกันสิบชั้นก็ทึบเหมือนเดิม |
| ลดขนาดจุด | อ่านตำแหน่งยากขึ้น แต่ตรงกลางยังนับไม่ได้อยู่ดี |
| เปลี่ยนสี | ไม่เกี่ยวกับปัญหาเลย |

**ปัญหาไม่ได้อยู่ที่การมองเห็น แต่อยู่ที่เรายังไม่ได้รวมข้อมูล**

1. สร้างกราฟใหม่ชนิด **deck.gl Grid** (หรือ **Hexagon**) จากพิกัดชุดเดิม
2. ที่ช่อง **Metric** เลือก `COUNT(*)`
3. ลองปรับ **Grid size** ให้เล็กลงและใหญ่ขึ้นอย่างละครั้ง
4. ตั้งชื่อ `ความหนาแน่นของที่อยู่แบบรวมช่อง <รหัสนักศึกษา>` บันทึกลงแดชบอร์ดเดิม

| Grid size | ข้อสรุปที่อ่านได้จากภาพ |
|---:|---|
| เล็กกว่าค่าเริ่มต้น | |
| ค่าเริ่มต้น | |
| ใหญ่กว่าค่าเริ่มต้น | |

> **ขนาดช่องเปลี่ยนข้อสรุปได้จริง**
> ช่องใหญ่เกินไปจะรวมพื้นที่ที่ไม่เกี่ยวกันเข้าด้วยกัน จนดูเหมือนทั้งย่านหนาแน่นเท่ากัน
> ช่องเล็กเกินไปจะกลับไปเหมือนจุดดิบที่อ่านความหนาแน่นไม่ออก
> **ไม่มีขนาดที่ถูกเพียงขนาดเดียว** ต้องเลือกให้เข้ากับคำถาม และบอกคนอ่านว่าเลือกเท่าไร


## ตอนที่ 3 — อธิบายวิธีอ่านแผนที่ (20 นาที)

แก้กล่อง **Markdown** บนแดชบอร์ดของคุณ ให้เพิ่มสามบรรทัดนี้

1. สีเข้มหรือช่องสูง แปลว่าอะไร
2. ขนาดช่องที่เลือกไว้เท่าไร
3. ข้อมูลมาจากไหนและครอบคลุมอะไร

> **แผนที่ที่ไม่มีคำอธิบายว่าสีแปลว่าอะไร คือแผนที่ที่คนอ่านต้องเดา**
> และเวลาคนเดา เขาจะเดาเข้าข้างสิ่งที่เขาเชื่ออยู่แล้ว

## Challenge (25 นาที) — ความหนาแน่นของจุด แทนอะไรกันแน่

แผนที่ของคุณกำลังแสดง **ความหนาแน่นของที่อยู่ที่ถูกบันทึกไว้ในฐานข้อมูล**
ซึ่งไม่ใช่สิ่งเดียวกับความหนาแน่นของประชากร และไม่ใช่ความหนาแน่นของกิจกรรมในเมือง

ลองกรองด้วย `POSTCODE` ทีละรหัส แล้วดูว่าภาพเปลี่ยนไปอย่างไร


> คำถามข้อ 3 คือหัวใจของแล็บนี้ — **สิ่งที่แผนที่นับ กับสิ่งที่คนอ่านคิดว่ามันนับ มักไม่ใช่อันเดียวกัน**
> และคนทำแผนที่มีหน้าที่บอกให้ชัดว่ากำลังนับอะไรอยู่

## บันทึกสัปดาห์นี้ (ต้องเขียน)

เปิดกล่อง Markdown บนแดชบอร์ดของคุณ แล้วเขียนต่อท้ายของเดิม

```markdown
## บันทึกสัปดาห์ที่ 9

(เขียนที่นี่ อย่างน้อย 60 ตัวอักษร)
```

**ห้ามลบบันทึกของสัปดาห์ก่อน** ตัวตรวจตรวจสะสม ลบแล้วตกย้อนหลัง
เหมือนลบกราฟเก่าทิ้ง

สิ่งที่ควรเขียนถึง

- เพิ่มจำนวนจุดจาก 10,000 เป็น 100,000 แล้วภาพบอกอะไรได้มากขึ้นบ้าง และอะไรที่แย่ลง
- เทียบสองกราฟ อะไรที่กราฟรวมจุดบอกได้แต่กราฟจุดดิบบอกไม่ได้ และในทางกลับกันมีอะไรที่หายไปบ้าง
- ช่องที่เข้มที่สุดบนแผนที่ แปลว่าบริเวณนั้นมีคนอยู่มากที่สุดจริงหรือไม่ มีคำอธิบายอื่นอะไรได้บ้าง

> เขียนสิ่งที่ **เห็น** ไม่ใช่สิ่งที่ **ทำ**
> "ทำกราฟเส้นเสร็จแล้ว" ไม่ได้บอกอะไรกับคนอ่าน
> "เปลี่ยนจาก SUM เป็น AVG แล้วรูปเปลี่ยนไปคนละเรื่อง" บอก
