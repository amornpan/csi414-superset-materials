## วัตถุประสงค์

1. ตั้ง **แคช** ให้สอดคล้องกับความสดของข้อมูล และรู้ว่าตั้งผิดแล้วเสียหายอย่างไร
2. ทดสอบว่า **คนอื่นเปิดงานของคุณได้จริงหรือไม่** ด้วยบัญชีที่ไม่ใช่ของคุณ
3. Export และ Import แดชบอร์ดข้ามเครื่องได้
4. เขียน **เอกสารส่งมอบ** ที่ทำให้คนรับงานต่อไม่ต้องเดา

> ### สัปดาห์นี้คือสัปดาห์สุดท้ายของภาคเรียนรู้เครื่องมือ
>
> แดชบอร์ดของคุณตอนนี้มีกราฟสิบกว่ารูป สองแท็บ ตัวกรอง Dataset เสมือน metric กลาง และแผนที่
> สัปดาห์หน้าคุณจะเริ่มโปรเจกต์ของตัวเอง และสิ่งที่ทำในคาบนี้คือสิ่งที่แยก
> **งานที่ทำเสร็จ** ออกจาก **งานที่ส่งมอบได้**

## ตอนที่ 1 — แคชที่ตั้งให้ตรงกับความจริง (30 นาที)

1. ไปที่ **Datasets** เปิด **Edit dataset** ของ `tutorial_flights`
2. ที่แท็บ **Settings** หาช่อง **Cache timeout** แล้วใส่ `3600` (หนึ่งชั่วโมง)
3. เปิดแดชบอร์ดแล้วสังเกตว่าโหลดครั้งที่สองเร็วกว่าครั้งแรกไหม

**คิดก่อนตั้ง — เติมตารางนี้**

| ข้อมูลแบบนี้ | ควรตั้งแคชเท่าไร | ถ้าตั้งนานเกินไปจะเกิดอะไร |
|---|---|---|
| ข้อมูลย้อนหลังที่ไม่เปลี่ยนแล้ว | | |
| ยอดขายที่อัปเดตทุกคืน | | |
| จำนวนคนในห้องที่อัปเดตทุกนาที | | |

> ### แคชคือการโกหกที่ตกลงกันไว้ล่วงหน้า
>
> เวลาตั้งแคชหนึ่งชั่วโมง คุณกำลังบอกว่า "ตัวเลขที่เก่าได้ถึงหนึ่งชั่วโมง ยังใช้ตัดสินใจได้"
> ถ้าข้อมูลจริงเปลี่ยนทุกนาที คนอ่านจะเห็นตัวเลขเก่า **โดยไม่มีอะไรบนหน้าจอบอกเขาเลย**
>
> เปิด **Dashboard Properties ‣ Styling ‣ Show last queried time** เสมอเมื่อใช้แคช
> เพื่อให้คนอ่านเห็นว่าตัวเลขนี้ดึงมาตอนไหน


## ตอนที่ 2 — คนอื่นเปิดได้จริงหรือเปล่า (30 นาที)

1. จับคู่กับเพื่อน แล้วส่ง URL แดชบอร์ดของคุณให้เขาเปิด
2. บันทึกว่าเกิดอะไรขึ้น

| ทดสอบ | ผลที่ได้ |
|---|---|
| เพื่อนเปิด URL แดชบอร์ดของคุณ | |
| เพื่อนเห็นกราฟครบไหม | |
| ถ้าเปิดไม่ได้ ระบบขึ้นข้อความว่าอะไร | |

> **แดชบอร์ดที่ยังเป็น Draft คนอื่นมองไม่เห็น** แม้จะรู้ URL ก็ตาม
> นี่คือเหตุผลที่ใบงานทุกสัปดาห์สั่งว่าห้าม Publish — งานของคุณจึงไม่ถูกลอกโดยอัตโนมัติ

3. ลอง **Publish** ชั่วคราวแล้วให้เพื่อนเปิดใหม่ บันทึกผล
4. **กลับไปตั้งเป็น Draft ก่อนส่งงาน** มิฉะนั้นระบบตรวจจะตก

**สองเงื่อนไขที่ต้องครบ คนอื่นถึงจะเห็นแดชบอร์ดได้**

| เงื่อนไข | ตรวจอย่างไร |
|---|---|
| แดชบอร์ดต้อง Published | ดูป้ายข้างชื่อแดชบอร์ด |
| เขาต้องมีสิทธิ์เข้าถึง **Dataset** ที่แดชบอร์ดใช้ | ถามผู้ดูแลระบบ หรือให้เขาลองเปิด Dataset ตรง ๆ |

## บันทึกสัปดาห์นี้ (ต้องเขียน)

เปิดกล่อง Markdown บนแดชบอร์ดของคุณ แล้วเขียนต่อท้ายของเดิม

```markdown
## บันทึกสัปดาห์ที่ 10

(เขียนที่นี่ อย่างน้อย 60 ตัวอักษร)
```

**ห้ามลบบันทึกของสัปดาห์ก่อน** ตัวตรวจตรวจสะสม ลบแล้วตกย้อนหลัง
เหมือนลบกราฟเก่าทิ้ง

สิ่งที่ควรเขียนถึง

- คุณตั้งแคชไว้เท่าไรและเพราะอะไร ถ้าข้อมูลชุดนี้อัปเดตทุกนาที คุณจะตั้งต่างไปอย่างไร
- คนที่รับงานของคุณไปทำต่อ ต้องรู้อะไรบ้างถึงจะทำงานต่อได้โดยไม่ต้องถามคุณ
- ตอนทดสอบด้วยบัญชีของเพื่อน คุณพบอะไรที่ไม่คาดคิด และมันเปลี่ยนวิธีที่คุณจะส่งมอบงานอย่างไร

> เขียนสิ่งที่ **เห็น** ไม่ใช่สิ่งที่ **ทำ**
> "ทำกราฟเส้นเสร็จแล้ว" ไม่ได้บอกอะไรกับคนอ่าน
> "เปลี่ยนจาก SUM เป็น AVG แล้วรูปเปลี่ยนไปคนละเรื่อง" บอก

## ส่งงาน

**ไม่ต้อง export ไม่ต้องอัปโหลดไฟล์** ระบบไปดึงแดชบอร์ดของคุณมาตรวจเอง

1. ตรวจให้แน่ใจว่าแดชบอร์ดชื่อ `csi414_<รหัส>` และคุณเป็นเจ้าของ
2. เขียนบันทึกใต้หัวข้อ `## บันทึกสัปดาห์ที่ 10` ในกล่อง Markdown
3. เข้า [ระบบส่งงาน](https://spu.minddatatech.com/assignment) แล้วกด **ลองตรวจ**
   ดูว่ายังขาดอะไร แก้จนพอใจแล้วค่อยกด **ส่งงาน**

**ห้าม Publish** ปล่อยไว้เป็น Draft

> กด **ลองตรวจ** ได้ตลอดเวลาโดยไม่นับเป็นการส่ง ใช้มันระหว่างทำงาน
> ไม่ใช่รอจนเสร็จแล้วค่อยกดครั้งเดียว
