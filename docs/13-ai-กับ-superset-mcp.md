# บทที่ 13 — ให้ AI ช่วยทำงานบน Superset ผ่าน MCP

บทนี้ไม่ได้อยู่ในคู่มือฉบับพิมพ์ เพราะเป็นความสามารถที่เพิ่งเป็นทางการในรุ่น 6.1
และเป็นเรื่องที่จะใช้จริงในโครงงานปลายภาค

## 13.1 MCP คืออะไร และทำไมถึงสำคัญกับวิชานี้

**MCP (Model Context Protocol)** คือมาตรฐานกลางที่ให้ผู้ช่วย AI ต่อเข้ากับโปรแกรมอื่นได้
Superset รุ่น 6.1 มี **MCP server ทางการ** มาให้ในตัว เปิดแล้วผู้ช่วย AI จะ

- ดูรายการ Dataset และ Dashboard ที่มีอยู่
- รัน SQL แล้วอ่านผลลัพธ์
- **สร้างกราฟและแดชบอร์ดให้ได้จริง** ไม่ใช่แค่บอกวิธีทำ

เอกสารทางการรองรับ Claude Desktop, **Claude Code (ผ่านไฟล์ `.mcp.json`)** และ ChatGPT
ต้องเป็น Superset 5.0 ขึ้นไป และผู้ดูแลต้องเปิด MCP server ไว้ก่อน

> **สิ่งที่ต้องเข้าใจให้ตรงกันก่อนใช้**
> MCP **ไม่ได้ข้ามระบบสิทธิ์** เอกสารทางการระบุว่า MCP บังคับใช้ RBAC เดิมของ Superset
> แปลว่า AI ทำได้เท่าที่บัญชีที่ใช้เชื่อมต่อทำได้ ถ้าบัญชีคุณเป็น Gamma
> AI ก็อัปโหลด CSV ให้ไม่ได้เหมือนกัน

## 13.2 เปิดใช้งาน (ฝั่งผู้ดูแล)

```bash
superset mcp run --host 127.0.0.1 --port 5008
```

การยืนยันตัวตนทำได้ 3 แบบตามเอกสารทางการ คือ JWT แบบ RS256 (ใช้ JWKS หรือคีย์ตายตัว)
JWT แบบ HS256 (ใช้ secret ร่วมกัน) หรือโหมดพัฒนาที่ระบุชื่อผู้ใช้ตายตัวโดยไม่ยืนยันตัวตน

> **อย่าใช้โหมดพัฒนาบนเซิร์ฟเวอร์ที่คนอื่นเข้าถึงได้**
> โหมดนั้นแปลว่าใครยิงเข้ามาก็เป็นผู้ใช้คนนั้นได้ทันที ใช้ได้เฉพาะบนเครื่องตัวเอง

## 13.3 ต่อ Claude Code เข้ากับ Superset

สร้างไฟล์ `.mcp.json` ไว้ในโฟลเดอร์โครงงานของคุณ

```bash
{
  "mcpServers": {
    "superset": {
      "type": "http",
      "url": "http://127.0.0.1:5008/mcp"
    }
  }
}
```

เปิด Claude Code ในโฟลเดอร์นั้น แล้วสั่งงานเป็นภาษาไทยได้เลย เช่น
"มี dataset อะไรบ้าง" · "ลองสรุปค่าตั๋วเฉลี่ยรายเดือนจาก tutorial_flights ให้หน่อย"

## 13.4 ใช้อย่างไรให้ได้ประโยชน์จริง ไม่ใช่แค่ขี้เกียจ

เอกสารทางการแนะนำ 3 ข้อ และวิชานี้เพิ่มอีก 2 ข้อ

| ข้อแนะนำ | เหตุผล |
|---|---|
| สั่งให้ชัดเจน ระบุ dataset คอลัมน์ และคำถามที่อยากตอบ | คำสั่งกว้าง ๆ ได้กราฟที่ดูดีแต่ไม่ตอบอะไร |
| เริ่มจากให้มันสำรวจ dataset ก่อน | AI ที่ไม่รู้ว่ามีคอลัมน์อะไร จะเดาชื่อคอลัมน์ |
| ใช้ preview ใน Explore ปรับก่อนบันทึกเสมอ | ค่าเริ่มต้นที่ AI เลือกมักไม่ใช่สิ่งที่คุณต้องการพอดี |
| **ตรวจตัวเลขด้วยตาตัวเองอย่างน้อย 1 จุด** | ถ้า AI เลือก aggregate ผิด (SUM แทน AVG) กราฟจะสวยและผิดพร้อมกัน |
| **อธิบายให้ได้ว่าทำไมถึงเลือกกราฟแบบนั้น** | ข้อสอบและการนำเสนอถามเหตุผล ไม่ได้ถามว่าใครสร้างให้ |

> **ข้อกำหนดของวิชา**
> ใช้ AI ช่วยทำแล็บได้ **แต่ต้องเขียนกำกับในช่องคำตอบว่าใช้ช่วยตรงไหน และคุณแก้อะไรต่อ**
> การส่งงานที่ AI สร้างทั้งหมดโดยไม่เข้าใจ จะถูกจับได้ตอนถามในคาบอยู่ดี
> และไม่ตรงกับเกณฑ์คะแนนซึ่งให้น้ำหนักกับ "อธิบายเหตุผลของการเลือก" มากกว่า "ทำได้"

## 13.5 ต่อยอดในโครงงานปลายภาค

โครงงานที่ทำ dashboard บนข้อมูลของกลุ่มตัวเอง ใช้ MCP ช่วยได้ในสามจังหวะ

1. **ตอนสำรวจข้อมูล** — ให้ AI รัน SQL หลาย ๆ แบบดูว่าข้อมูลหน้าตาเป็นอย่างไร เร็วกว่าเขียนเองทีละคำสั่ง
2. **ตอนร่างกราฟ** — ให้สร้างกราฟ 3–4 แบบจากคำถามเดียวกัน แล้วเลือกเองว่าอันไหนตอบคำถามดีที่สุด
3. **ตอนตรวจงานตัวเอง** — ให้ช่วยไล่ว่าแดชบอร์ดมีกราฟไหนที่ไม่มีคำถามรองรับบ้าง

**สิ่งที่ยังต้องเป็นคนทำเอง** — ตัดสินใจว่าคำถามอะไรสำคัญ · เลือกว่าจะสื่อสารกับใคร ·
และรับผิดชอบว่าตัวเลขบนจอถูกต้อง
