# ภาคผนวก

### ก. คำสั่ง Docker ที่ใช้บ่อย

```bash
# เข้าโฟลเดอร์โครงการก่อนทุกครั้ง
cd superset
# เปิดใช้งาน แบบเห็นข้อความทั้งหมด
docker compose -f docker-compose-image-tag.yml up
# เปิดใช้งาน แบบทำงานเบื้องหลัง
docker compose -f docker-compose-image-tag.yml up -d
# ดูสถานะทุก container
docker compose ps
# ดูข้อความจากตัวโปรแกรมหลัก
docker compose logs -f superset_app
# หยุดชั่วคราว (แนะนำ)
docker compose stop
# เปิดใหม่หลังหยุด
docker compose start
# ปิดและลบ container
docker compose down
# เข้าไปในเครื่อง container เพื่อใช้คำสั่งของ Superset เอง
docker exec -it superset_app bash
# สร้างบัญชีผู้ดูแลระบบใหม่ (ใช้ภายใน container)
superset fab create-admin
```

### ข. สรุปเส้นทางเมนูทั้งหมด

| **งาน**               | **เส้นทาง**                                         |
|:----------------------|:---------------------------------------------------|
| เชื่อมต่อฐานข้อมูล         | \+ ‣ Data ‣ Connect database                       |
| แก้ไขการเชื่อมต่อ         | Settings ‣ Data ‣ Database Connections ‣ ไอคอนดินสอ |
| อัปโหลด CSV            | \+ ‣ Data ‣ Upload CSV to database                 |
| สร้าง Dataset          | \+ ‣ Data ‣ Create dataset                         |
| แก้ไข Dataset และตัวชี้วัด | Datasets ‣ ชี้ที่แถว ‣ ไอคอนดินสอ                       |
| สร้างกราฟ              | \+ ‣ Chart                                         |
| สร้างแดชบอร์ด           | \+ ‣ Dashboard                                     |
| เขียน SQL              | SQL ‣ SQL Lab                                      |
| ดูประวัติคิวรี             | SQL ‣ Query history                                |
| จัดการผู้ใช้              | Settings ‣ Manage ‣ List Users                     |
| จัดการบทบาทและสิทธิ์      | Settings ‣ Manage ‣ List Roles                     |
| ชั้นเหตุการณ์บนกราฟ       | Settings ‣ Manage ‣ Annotation Layers              |
| แต่งสีด้วย CSS           | Settings ‣ Manage ‣ CSS Templates                  |
| ตั้งรายงานและการแจ้งเตือน | Settings ‣ Manage ‣ Alerts & Reports               |

### ค. อภิธานศัพท์

| **คำศัพท์**         | **ความหมาย**                                   |
|:------------------|:-----------------------------------------------|
| Chart / Slice     | กราฟหนึ่งรูปที่บันทึกไว้                               |
| Dashboard         | หน้ารวมกราฟหลายรูปพร้อมตัวกรองใช้ร่วมกัน              |
| Dataset           | ตารางหรือผลลัพธ์ SQL ที่ประกาศให้ใช้สร้างกราฟได้        |
| Physical dataset  | Dataset ที่ชี้ตรงไปยังตารางจริงในฐานข้อมูล             |
| Virtual dataset   | Dataset ที่เกิดจากคำสั่ง SQL แทนชื่อตาราง             |
| Metric            | สูตรรวมยอด เช่น SUM, COUNT, AVG ที่นิยามไว้ที่ Dataset |
| Calculated column | คอลัมน์คำนวณระดับแถว ห้ามใช้ฟังก์ชันรวมยอด             |
| Dimension         | คอลัมน์ที่ใช้จัดกลุ่ม เทียบได้กับ GROUP BY                |
| Explore           | หน้าจอสร้างกราฟแบบไม่ต้องเขียนโค้ด                   |
| SQL Lab           | หน้าจอเขียนคำสั่ง SQL ด้วยตัวเอง                     |
| Semantic layer    | ชั้นนิยามตัวชี้วัดกลางเพื่อให้ทุกคนใช้สูตรเดียวกัน            |
| Native filter     | ตัวกรองระดับแดชบอร์ดที่มีผลกับหลายกราฟพร้อมกัน          |
| Cross-filter      | การคลิกที่กราฟหนึ่งแล้วกราฟอื่นถูกกรองตาม               |
| Drill to detail   | การดูข้อมูลระดับแถวที่อยู่เบื้องหลังตัวเลข                 |
| Drill by          | การหั่นตัวเลขเดิมด้วยคอลัมน์อื่นทันที                     |
| Time grain        | ระดับความละเอียดของเวลา เช่น วัน สัปดาห์ เดือน        |
| Row limit         | จำนวนแถวสูงสุดที่ดึงมาแสดง                          |
| Metadata database | ฐานข้อมูลที่ Superset ใช้เก็บนิยามงานของตัวเอง         |
| Feature flag      | สวิตช์เปิดปิดคุณสมบัติที่ผู้ดูแลระบบตั้งในไฟล์ตั้งค่า            |
| Jinja templating  | ไวยากรณ์แทรกตัวแปรลงในคำสั่ง SQL                   |
