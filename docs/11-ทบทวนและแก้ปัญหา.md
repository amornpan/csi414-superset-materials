# บทที่ 11 — ทบทวน แก้ปัญหา และแบบฝึกหัดส่งท้าย

## 11.1 รายการตรวจสอบก่อนส่งมอบแดชบอร์ด

| **✓** | **สิ่งที่ต้องตรวจ** | **เหตุผล** |
|:---|:---|:---|
|  | ตัวเลขบนกราฟตรงกับตัวเลขที่คำนวณด้วยวิธีอื่น | ตรวจด้วย SQL Lab หรือ Excel อย่างน้อยหนึ่งจุด |
|  | ช่วงเวลาเริ่มต้นเหมาะกับผู้ใช้ | ค่าเริ่มต้นคือย้อนหลัง 1 สัปดาห์ ซึ่งมักไม่ใช่สิ่งที่ต้องการ |
|  | ทุกกราฟมีชื่อที่คนอ่านเข้าใจ | ชื่ออย่าง Chart 1 ทำให้ไม่มีใครกล้าใช้ |
|  | มีกล่องข้อความอธิบายที่มา รอบการปรับปรุง และผู้รับผิดชอบ | ลดคำถามซ้ำและสร้างความน่าเชื่อถือ |
|  | ทดสอบด้วยบัญชี Gamma ว่ามองเห็นได้จริง | หลายครั้งแดชบอร์ดเปิดได้เฉพาะเจ้าของ เพราะยังไม่ได้ให้สิทธิ์ Dataset |
|  | เปลี่ยนสถานะเป็น Published แล้ว | สถานะ Draft คนอื่นเปิดไม่เห็น |
|  | รอบรีเฟรชอัตโนมัติไม่ถี่เกินไป | ป้องกันภาระที่ไม่จำเป็นต่อฐานข้อมูล |
|  | ลองเปิดบนหน้าจอขนาดเล็ก | หัวหน้ามักเปิดดูจากมือถือ |

## 11.2 ปัญหาที่พบบ่อยและวิธีแก้

| **อาการ** | **สาเหตุที่พบบ่อยที่สุด** | **วิธีแก้** |
|:---|:---|:---|
| กราฟว่างเปล่า ไม่มีข้อมูล | ช่วงเวลาเริ่มต้นคือย้อนหลัง 1 สัปดาห์ แต่ข้อมูลเก่ากว่านั้น | เปลี่ยน Time range เป็น No filter หรือกำหนดช่วงเองให้ครอบคลุมข้อมูล |
| แก้ค่าแล้วกราฟไม่เปลี่ยน | ยังไม่ได้กดปุ่ม Create chart หรือ Run | กดปุ่มทุกครั้งหลังแก้ค่า |
| ตัวเลขเก่าไม่อัปเดต | ผลลัพธ์ถูกเก็บไว้ในแคช | กด Force refresh จากเมนูจุดสามจุด หรือลดค่า Chart cache timeout |
| หาคอลัมน์เวลาไม่เจอ | คอลัมน์นั้นยังไม่ได้ติ๊ก Is temporal หรืออัปโหลด CSV โดยไม่ได้ระบุคอลัมน์วันที่ | แก้ไข Dataset แล้วติ๊ก Is temporal หรืออัปโหลดใหม่พร้อมกรอกช่อง Columns to be parsed as dates |
| ลากคอลัมน์ใส่ Dimensions ไม่ได้ | คอลัมน์ยังไม่ได้ติ๊ก Is dimension | แก้ไข Dataset ในแท็บ Columns |
| เชื่อมต่อฐานข้อมูลไม่ได้ ขึ้นว่า port is closed | Superset อยู่ใน container จึงมองไม่เห็น localhost ของเครื่อง | เปลี่ยนค่า host เป็น host.docker.internal |
| บันทึกกราฟแล้วเพื่อนเปิดไม่ได้ | เพื่อนยังไม่มีสิทธิ์เข้าถึง Dataset ที่ใช้ | ให้สิทธิ์ผ่าน Roles หรือใช้ Dataset ที่แชร์ไว้แล้ว |
| คิวรีค้างนานมาก | ข้อมูลใหญ่เกินไปหรือไม่มีดัชนีรองรับ | ลดช่วงเวลา ลด Row limit หรือสร้างตารางสรุปไว้ล่วงหน้าในฐานข้อมูล |
| ขึ้นรหัสข้อผิดพลาดเป็นตัวเลข | Superset มีรหัสปัญหาเฉพาะของตัวเอง | ค้นรหัสนั้นในหน้า Issue Codes ของเอกสารทางการ จะมีคำอธิบายและวิธีแก้ |

## 11.3 แบบฝึกหัดส่งท้าย

ทำโจทย์นี้ให้จบด้วยตัวเองโดยไม่เปิดคู่มือ ถ้าทำได้ทั้งหมดถือว่าใช้ Superset เป็นแล้ว

1.  เชื่อมต่อฐานข้อมูล examples แล้วยืนยันด้วยปุ่ม Test Connection ว่าผ่าน

2.  อัปโหลดไฟล์ tutorial_flights.csv เข้าเป็นตารางใหม่ พร้อมระบุคอลัมน์ Travel Date เป็นคอลัมน์วันที่

3.  สร้างตัวชี้วัดชื่อ avg_cost ด้วยสูตร AVG(cost) ในแท็บ Metrics ของ Dataset

4.  สร้างคอลัมน์คำนวณชื่อ cost_per_km ด้วยสูตร CAST(cost AS FLOAT) / NULLIF(distance, 0)

5.  สร้างกราฟ Big Number แสดงค่าตั๋วรวมทั้งชุดข้อมูล

6.  สร้างกราฟ Bar Chart แสดงค่าใช้จ่ายรวมแยกตามหน่วยงาน

7.  สร้างกราฟ Line Chart แสดงราคาตั๋วเฉลี่ยรายเดือน พร้อมเปิดเฉลี่ยเคลื่อนที่ 3 เดือน

8.  นำทั้งสามกราฟมาวางบนแดชบอร์ดใหม่ชื่อ แดชบอร์ดฝึกหัดของฉัน

9.  เพิ่มกล่องข้อความอธิบายที่มาของข้อมูลไว้ด้านบนสุด

10. เพิ่มตัวกรองแบบ Value บนคอลัมน์ Travel Class และตัวกรองช่วงเวลาบน Travel Date

11. ทดลองคลิกที่แท่งกราฟหนึ่งแท่ง เพื่อดูว่ากราฟอื่นถูกกรองตามหรือไม่

12. เปลี่ยนสถานะเป็น Published และกดดาวไว้

13. ส่งออกแดชบอร์ดเป็นไฟล์ .zip เก็บไว้

> **ทำต่อจากนี้อย่างไร**
> ลองนำข้อมูลจริงของหน่วยงานคุณมาทำซ้ำทั้งกระบวนการ เริ่มจากคำถามทางธุรกิจหนึ่งข้อ แล้วสร้างกราฟตอบคำถามนั้นให้ได้
> ศึกษาการตั้งค่ารายงานตามกำหนดเวลา (Reports) และการแจ้งเตือน (Alerts) ซึ่งต้องมี Celery worker ทำงานอยู่
> หากจะใช้จริงในองค์กร ให้ศึกษาการติดตั้งบน Kubernetes การตั้งค่าความปลอดภัย และการเชื่อมกับระบบล็อกอินกลางขององค์กร
