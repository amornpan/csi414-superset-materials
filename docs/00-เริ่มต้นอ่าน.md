### เริ่มต้นอ่านคู่มือเล่มนี้อย่างไร

คู่มือเล่มนี้เขียนขึ้นสำหรับคนที่ยังไม่เคยแตะ Apache Superset มาก่อนเลย ทุกบทออกแบบให้ทำตามได้จริงบนเครื่องของตัวเอง โดยไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องขอสิทธิ์จากใคร และไม่ต้องเขียนโปรแกรมเป็น

สิ่งที่คุณจะทำได้เมื่ออ่านจบ

- ติดตั้ง Superset บนเครื่องตัวเองด้วย Docker ภายในเวลาประมาณ 15 นาที

- เชื่อมต่อฐานข้อมูลของหน่วยงานเข้ากับ Superset และทดสอบการเชื่อมต่อจนผ่าน

- นำไฟล์ CSV ขึ้นเป็นตาราง แล้วประกาศเป็น Dataset

- สร้างกราฟ 3 แบบด้วยตัวเอง คือ ตาราง (Table), ตารางไขว้ (Pivot Table) และกราฟเส้น (Line Chart)

- ประกอบกราฟทั้งหมดเป็นแดชบอร์ด ใส่ตัวกรอง จัดหน้า และเผยแพร่ให้เพื่อนร่วมงานดู

- ใช้ SQL Lab เขียนคำสั่ง SQL เอง แล้วเปลี่ยนผลลัพธ์เป็นกราฟ

- กำหนดสิทธิ์ผู้ใช้ และย้ายงานที่ทำไว้ไปยังเซิร์ฟเวอร์อื่น

### สัญลักษณ์ที่ใช้ในเล่ม

| **สัญลักษณ์** | **ความหมาย** |
|:---|:---|
| ตัวเลข ① ② ③ ในภาพ | ตำแหน่งบนหน้าจอที่กำลังอธิบาย จะมีคำอธิบายเรียงตามหมายเลขอยู่ใต้ภาพเสมอ |
| **กล่องสีเทา** | คำสั่งที่ต้องพิมพ์ หรือข้อความที่ต้องกรอกลงช่อง ให้พิมพ์ตามตรงตัวอักษร |
| **กล่องสีเขียว** | เคล็ดลับที่ช่วยให้ทำงานเร็วขึ้น ข้ามได้ถ้ารีบ |
| **กล่องสีแดง** | ข้อควรระวัง อ่านก่อนกดปุ่ม เพราะแก้ทีหลังยาก |
| **กล่องสีฟ้า** | ข้อมูลเสริมและคำอธิบายเชิงแนวคิด |
| เมนู A ‣ B ‣ C | หมายถึงให้คลิกเมนู A แล้วเลือก B แล้วเลือก C ตามลำดับ |

> **หน้าตาโปรแกรมอาจต่างจากภาพเล็กน้อย**
> ภาพประกอบทุกภาพในเล่มนี้เป็นภาพวาดจำลองหน้าจอ (ไม่ใช่ภาพถ่ายหน้าจอจริง) เพื่อให้เห็นโครงและตำแหน่งของสิ่งที่ต้องกดได้ชัดที่สุด ป้ายชื่อปุ่มและช่องต่าง ๆ ใช้ภาษาอังกฤษตรงกับที่ปรากฏจริงในโปรแกรม
> Superset ออกรุ่นใหม่บ่อยมาก ปุ่มบางปุ่มอาจย้ายที่หรือเปลี่ยนชื่อเล็กน้อย แต่ลำดับขั้นตอนการทำงานยังเหมือนเดิม หากหาปุ่มไม่พบ ให้มองหาชื่อภาษาอังกฤษที่ระบุไว้ในคู่มือแทนตำแหน่ง
